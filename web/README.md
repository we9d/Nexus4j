# Palm LCI Portal (เว็บต้นแบบกลุ่ม S02-G07)

เว็บใช้ข้อมูล โมเดล และค่าตั้งเดียวกับบท 6.5
- **Chunk**: KC001 ถึง KC040
- **Embedding Model**: `paraphrase-multilingual-MiniLM-L12-v2` (384 มิติ)
- **พารามิเตอร์**: $k = 5$, เกณฑ์ความคล้าย 0.40
- **ฐานข้อมูล**: ค่าเริ่มต้นเก็บเวกเตอร์ในหน่วยความจำ ถ้าตั้งค่า Supabase จะค้นและ UPSERT บนตาราง `knowledge_chunks` จริง (ดูหัวข้อ [เชื่อม Supabase](#เชื่อม-supabase-ไม่บังคับ))

---

## หน้าเว็บทั้ง 8 หน้า

1. **ภาพรวม**: ห่วงโซ่การผลิต ก๊าซเรือนกระจกรายขั้นตอน และภาพสถาปัตยกรรมฝั่งนำเข้าและฝั่งค้นคืน
2. **ถามจากหลักฐาน**: ค้น 5 อันดับพร้อม `chunk_id` และ `source_id` แล้วตอบจากหลักฐาน กดถาม Gemini เพื่อให้เรียบเรียง หรือเลือกเวกเตอร์ร่วมกับกราฟ Multi-hop เพื่อเทียบสองวิธีและดูเส้นทางในกราฟ
3. **คลัง Chunk**: Chunk ทั้ง 40 รายการ พร้อมกระบวนการ ค่า แหล่งข้อมูล ตำแหน่งในเอกสาร และภาพ Heatmap กับ PCA
4. **ผลประเมิน**: ผลรอบทางการ 5 ข้อ ตรงกับตารางในเล่ม และปุ่มรันใหม่จากหลักฐานหรือด้วย Gemini
5. **แก้ข้อมูล**: แก้ค่าใน Chunk แล้วเขียนทับแถวเดิม แสดงคำตอบก่อนและหลัง มีแถบเตือนและปุ่มคืนค่าเดิม
6. **สถิติการผลิต**: ผลผลิตและเนื้อที่ปลูกทั้งประเทศ จังหวัดผู้ผลิตสูงสุดรายปี ผลผลิตรายภาค และน้ำรายภาค
7. **บัญชีรายการ**: Input และ Output ของทุกกระบวนการ พร้อมแหล่งข้อมูลและผลการตรวจสอบ ดาวน์โหลด CSV ได้
8. **แหล่งข้อมูล**: แหล่งข้อมูลทั้ง 6 แหล่ง พร้อมลิงก์เอกสาร

## ลำดับสาธิตให้ครบ 8 เกณฑ์ของ M4

- **เกณฑ์ 1 และ 2**: หน้าภาพรวม เล่าโจทย์ แล้วชี้ภาพสถาปัตยกรรมฝั่งนำเข้าและฝั่งค้นคืน
- **เกณฑ์ 3**: เปิดไฟล์ DDL ของ `knowledge_chunks` ในเล่มหรือใน Supabase ประกอบ
- **เกณฑ์ 4**: หน้าคลัง Chunk แสดง 40 รายการพร้อมแหล่งที่มา
- **เกณฑ์ 5**: หน้าถามจากหลักฐาน กดคำถามข้อแรก ให้ดู 5 อันดับ คะแนน `chunk_id` และ `source_id`
- **เกณฑ์ 6**: กดคำถามเรื่องวารสาร ระบบสลับเป็นโหมดกราฟเอง (วิธีที่ 1 ไม่พบชื่อวารสาร / วิธีที่ 2 พบ)
- **เกณฑ์ 7**: หน้าผลประเมิน คะแนนเฉลี่ย 3.00 และ P@5 0.20
- **เกณฑ์ 8**: หน้าแก้ข้อมูล ใช้ค่าเริ่มต้น KC022 เป็น 6.20 กดแก้และเขียนทับ จำนวนแถวยังเป็น 40 แล้วกด **คืนค่าเดิม** ที่แถบด้านบนทุกครั้งก่อนไปหน้าอื่น

## วิธีติดตั้งและรันเว็บ

### 1. เข้าโฟลเดอร์ web
```bash
cd web
```

### 2. สร้างและเปิด Virtual Environment (ครั้งแรกครั้งเดียว)
```bash
python3 -m venv .venv
source .venv/bin/activate       # บน Mac / Linux
# .venv\Scripts\activate        # บน Windows PowerShell
pip install -r requirements.txt
```

### 3. ตั้งค่าไฟล์ `.env`
สร้างหรือแก้ไขไฟล์ `.env` ในโฟลเดอร์ `web/` (ไฟล์นี้อยู่ใน `.gitignore` ไม่ถูก commit):
```env
GEMINI_API_KEY="วางคีย์ตรงนี้"
SUPABASE_DB_URL="postgresql://..."
```
*(ถ้าไม่ใส่คีย์ เว็บยังใช้ได้ครบ เพียงแต่ไม่มีปุ่ม Gemini และค้นจากหน่วยความจำแทน)*

### 4. รันเว็บ
```bash
python app.py
```
รอจนขึ้นข้อความ:
> `เปิดเบราว์เซอร์ที่ http://127.0.0.1:8081`

แล้วเปิดลิงก์ในเบราว์เซอร์

### 5. ปิดเว็บ
กด `Ctrl + C` ใน Terminal

## ค่าตั้งเพิ่มเติมที่เปลี่ยนได้ (Environment Variables)

- `GEMINI_MODEL`: ค่าเริ่มต้น `"gemini-3.5-flash"` (รุ่นหลัก ตรงกับผลในเล่ม)
- `GEMINI_FALLBACK`: ค่าเริ่มต้น `"gemini-3.5-flash-lite"` (รุ่นสำรอง)
- `GEMINI_TIMEOUT_S`: เวลารอสูงสุด ค่าเริ่มต้น `12` วินาที
- `DEMO_EDIT`: ตั้งเป็น `"0"` หากต้องการซ่อนหน้าแก้ข้อมูล

## เชื่อม Supabase (ไม่บังคับ)

เว็บจะค้นด้วยคำสั่ง `ORDER BY embedding <=> ... LIMIT 5` และ UPSERT ด้วย `INSERT ON CONFLICT DO UPDATE` เหมือน Colab ขั้นตอนที่ 9 และ 10

### วิธีตั้งค่าใน `.env`:
- **แบบที่ 1 (แนะนำ)**: ใช้ Connection String จากปุ่ม Connect ในหน้าโปรเจกต์ Supabase (เลือก Session pooler)
  ```env
  SUPABASE_DB_URL="postgresql://..."
  ```
- **แบบที่ 2**: ระบุแยกตัวแปร
  ```env
  SUPABASE_HOST="ค่า Host"
  SUPABASE_PORT="5432"
  SUPABASE_DB="postgres"
  SUPABASE_USER="ค่า User"
  SUPABASE_PASSWORD="รหัสผ่าน"
  ```

เมื่อรัน `python app.py` บรรทัด **ฐานข้อมูลเวกเตอร์** จะขึ้นว่า:
> `ค้นด้วย pgvector บน Supabase ตาราง public.knowledge_chunks 40 แถว`

### สิ่งที่ระบบจัดการให้อัตโนมัติ:
- ตรวจว่าตารางมี 40 แถว รหัสตรงกับเล่ม และสร้างด้วยโมเดล `paraphrase-multilingual-MiniLM-L12-v2` ถ้าไม่ตรงจะไม่ใช้ Supabase
- ถ้ามีแถวที่ข้อความต่างจากเล่ม (เช่นค่า 6.20 ค้างจากการสาธิต) จะขึ้นแถบเตือนให้กดคืนค่าเดิม
- ถ้าเชื่อมต่อหลุดระหว่างค้นหา จะ fallback ไปค้นจากหน่วยความจำแทนโดยอัตโนมัติ
- เมื่อปิดเว็บด้วย `Ctrl + C` ระบบจะคืนค่าเดิมบน Supabase ให้

### ข้อควรระวัง:
- หน้าแก้ข้อมูลเขียนลงฐานข้อมูลจริง **กดคืนค่าเดิมทุกครั้งหลังสาธิต**
- โหมดทดสอบ `S02G07_TEST_EMBEDDER=1` จะไม่ต่อ Supabase เพื่อไม่ให้เวกเตอร์ทดสอบทับของจริง
