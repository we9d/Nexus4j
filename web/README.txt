Palm LCI Portal  เว็บต้นแบบของกลุ่ม S02-G07

เว็บใช้ข้อมูล โมเดล และค่าตั้งเดียวกับบท 6.5
  Chunk KC001 ถึง KC040  โมเดล paraphrase-multilingual-MiniLM-L12-v2  k เท่ากับ 5  เกณฑ์ความคล้าย 0.40
  ค่าเริ่มต้นเก็บเวกเตอร์ในหน่วยความจำ ถ้าตั้งค่า Supabase จะค้นและ UPSERT บนตาราง knowledge_chunks จริง (ดูหัวข้อ เชื่อม Supabase)

หน้าเว็บมี 8 หน้า
  ภาพรวม            ห่วงโซ่การผลิต ก๊าซเรือนกระจกรายขั้นตอน และภาพสถาปัตยกรรมฝั่งนำเข้าและฝั่งค้นคืน
  ถามจากหลักฐาน     ค้นห้าอันดับพร้อม chunk_id และ source_id แล้วตอบจากหลักฐาน กด ถาม Gemini เพื่อให้เรียบเรียง
                    เลือก เวกเตอร์ร่วมกับกราฟ Multi-hop เพื่อเทียบสองวิธีและดูเส้นทางในกราฟ
  คลัง Chunk         Chunk ทั้ง 40 รายการ พร้อมกระบวนการ ค่า แหล่งข้อมูล ตำแหน่งในเอกสาร และภาพ Heatmap กับ PCA
  ผลประเมิน          ผลรอบทางการ 5 ข้อ ตรงกับตารางในเล่ม และปุ่มรันใหม่จากหลักฐานหรือด้วย Gemini
  แก้ข้อมูล          แก้ค่าใน Chunk แล้วเขียนทับแถวเดิม แสดงคำตอบก่อนและหลัง มีแถบเตือนและปุ่มคืนค่าเดิม
  สถิติการผลิต       ผลผลิตและเนื้อที่ปลูกทั้งประเทศ จังหวัดผู้ผลิตสูงสุดรายปี ผลผลิตรายภาค และน้ำรายภาค
  บัญชีรายการ       Input และ Output ของทุกกระบวนการ พร้อมแหล่งข้อมูลและผลการตรวจสอบ ดาวน์โหลด CSV ได้
  แหล่งข้อมูล        แหล่งข้อมูลทั้ง 6 แหล่ง พร้อมลิงก์เอกสาร

  5        หน้าถามจากหลักฐาน กดคำถามข้อแรก ให้ดูห้าอันดับ คะแนน chunk_id และ source_id
  6        กดคำถามเรื่องวารสาร ระบบสลับเป็นโหมดกราฟเอง วิธีที่ 1 ไม่พบชื่อวารสาร วิธีที่ 2 พบ

วิธีรันบน Mac
  1  เปิด Terminal แล้วเข้าโฟลเดอร์นี้
       cd ที่อยู่ของ repo Nexus4j/web
  2  สร้างและเปิด venv ครั้งแรกครั้งเดียว
       python3 -m venv .venv
       source .venv/bin/activate
       pip install -r requirements.txt
     ครั้งต่อไปพิมพ์แค่ source .venv/bin/activate
  3  ใส่คีย์ Gemini และค่า Supabase (ถ้ามี) ในไฟล์ .env ที่โฟลเดอร์ web (ไฟล์นี้อยู่ใน .gitignore ห้าม commit)
       GEMINI_API_KEY="วางคีย์ตรงนี้"
       SUPABASE_DB_URL="postgresql://..."
     ถ้าไม่ใส่คีย์ เว็บยังใช้ได้ครบ แค่ไม่มีปุ่ม Gemini และค้นจากหน่วยความจำแทน
  4  รันเว็บ
       python app.py
     รอจนขึ้นว่า เปิดเบราว์เซอร์ที่ http://127.0.0.1:8081 แล้วเปิดลิงก์นั้นใน Chrome หรือ Safari
  5  ปิดเว็บ กด Control และ C ใน Terminal

ทดสอบก่อนนำเสนอ
  ในโฟลเดอร์นี้ที่เปิด venv และ export คีย์แล้ว พิมพ์
       python3 tests/selftest.py
  สคริปต์ตรวจ Q1 ถึง Q5 การเดินกราฟ การประเมิน และการแก้ค่าแล้วคืนค่า ด้วยโมเดลจริง
  ถ้าตั้งคีย์ไว้จะลองเรียก Gemini จริงด้วย สคริปต์ไม่พิมพ์คีย์ออกมา

ค่าตั้งที่เปลี่ยนได้ก่อนรัน
  export GEMINI_MODEL="gemini-3.5-flash"          รุ่นหลัก ตรงกับรุ่นที่ใช้ทำผลในเล่ม
  export GEMINI_FALLBACK="gemini-3.5-flash-lite"  รุ่นสำรอง ใช้เมื่อรุ่นหลักตอบรหัส 404 429 500 หรือ 503
  export GEMINI_TIMEOUT_S="20"                    เวลารอสูงสุด ค่าเริ่มต้น 12 วินาที
  export DEMO_EDIT="0"                            ซ่อนหน้าแก้ข้อมูล
  คำตอบจาก Gemini แสดงชื่อรุ่นที่ตอบจริงทุกครั้ง ถ้ารุ่นหลักช้าเกินเวลารอ ให้สลับเป็นรุ่น lite ด้วย GEMINI_MODEL

หมายเหตุ
  รันครั้งแรกจะดาวน์โหลดโมเดล MiniLM ถ้าเครื่องเคยรันงาน 6.5 มาแล้วจะใช้ไฟล์เดิมได้ทันที
  มุมขวาบนของเว็บต้องขึ้นว่า โมเดลค้นหาพร้อม และชื่อรุ่น Gemini ก่อนนำเสนอ
  การแก้ข้อมูลในเว็บไม่เขียนลง Supabase และหายเมื่อปิดเว็บ
  ต้องต่ออินเทอร์เน็ตตอนใช้ Gemini และตอนเปิดลิงก์เอกสารในหน้าแหล่งข้อมูล

เชื่อม Supabase (ไม่บังคับ)
  เว็บจะค้นด้วยคำสั่ง ORDER BY embedding <=> ... LIMIT 5 และ UPSERT ด้วย INSERT ON CONFLICT DO UPDATE เหมือน Colab ขั้นตอนที่ 9 และ 10
  ใส่ในไฟล์ .env ที่โฟลเดอร์ web (ไฟล์นี้อยู่ใน .gitignore ห้าม commit) หรือตั้งค่าใน Terminal
  แบบที่ 1 connection string จากปุ่ม Connect ในหน้าโปรเจกต์ Supabase (เลือก Session pooler)
       SUPABASE_DB_URL="postgresql://..."
  แบบที่ 2 ค่าเดียวกับที่กรอกใน Colab ขั้นตอนที่ 7
       SUPABASE_HOST="ค่า Host"
       SUPABASE_PORT="5432"
       SUPABASE_DB="postgres"
       SUPABASE_USER="ค่า User"
       SUPABASE_PASSWORD="รหัสผ่าน"
  แล้วรัน python app.py ตามปกติ บรรทัด ฐานข้อมูลเวกเตอร์ ต้องขึ้นว่า ค้นด้วย pgvector บน Supabase ตาราง public.knowledge_chunks 40 แถว
  มุมขวาบนของเว็บจะขึ้นว่า Supabase pgvector
  สิ่งที่ระบบทำให้เอง
    ตรวจว่าตารางมี 40 แถว รหัสตรงกับเล่ม และสร้างด้วยโมเดล paraphrase-multilingual-MiniLM-L12-v2 ถ้าไม่ตรงจะไม่ใช้ Supabase
    ถ้ามีแถวที่ข้อความต่างจากเล่ม เช่นค่า 6.20 ค้างจากการสาธิตครั้งก่อน จะขึ้นแถบเตือนให้กดคืนค่าเดิม
    ถ้าเชื่อมต่อหลุดระหว่างค้นหา จะค้นจากหน่วยความจำแทนโดยอัตโนมัติ
    เมื่อปิดเว็บด้วย Control และ C จะคืนค่าเดิมบน Supabase ให้
  ข้อควรระวัง
    หน้าแก้ข้อมูลเขียนลงฐานข้อมูลจริง กดคืนค่าเดิมทุกครั้งหลังสาธิต
    ถ้าไม่ต้องการให้แก้ข้อมูลบน Supabase ให้ export DEMO_EDIT="0"
    โหมดทดสอบ S02G07_TEST_EMBEDDER=1 จะไม่ต่อ Supabase เพื่อไม่ให้เวกเตอร์ทดสอบทับของจริง
    ถ้า Host แบบ db.xxx.supabase.co เชื่อมไม่ได้ ให้ใช้ค่าจาก Session pooler แทน
